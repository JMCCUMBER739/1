Automated email intake (for IT)

A mail gateway or scheduled IMAP poller can post submissions to the API so the team can simply email documents in. Endpoint:

POST {{ url_for('intake.api', _external=True) }}
Header:  X-Intake-Token: <ENGCMMS_INTAKE_TOKEN>
Form:    type=IP  project=DX-101  from=jane@lab  subject=...  apply=1
File:    file=<the attached document>

Set ENGCMMS_INTAKE_TOKEN to enable the API. Map the email subject prefix (IP:, REQ:, CDR:, …) to type, and a project code to project. A ready-to-use poller is in tools/mail_poller.py.
