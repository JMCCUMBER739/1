# Palimpsest (in this repository)

This branch adds **[Palimpsest](./palimpsest/)** — a production Book Restoration & Intelligence Studio for scanned PDFs.

See [`palimpsest/README.md`](./palimpsest/README.md) for install, GUI, CLI, and output layout.

```bash
cd palimpsest
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
./run_gui.sh
```
